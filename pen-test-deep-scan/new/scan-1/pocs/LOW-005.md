# PoC: LOW-005 — §16.4 worker contract vs shipped `PPXWorkerRequest`

Non-harmful documentation/contract diff. No runtime exploit; demonstrates the two
extra request kinds and two extra completed-result types that §16.4 does not list.

## Normative `PPXWorkerRequest` per `docs/security-architecture.md:§16.4` (lines 675-709)

```
encrypt-text | decrypt-text | encrypt-file | decrypt-file | unlock-vault | lock-vault | cancel
```

Normative `PPXWorkerEvent` `completed` result unions (lines 723-734):

```
variant A: EncryptedTextObject | EncryptedFileObject | EncryptedFileBlobOutput | LockedVaultObject | DerivedIdentity
variant B: DecryptedTextOutput | DecryptedFileOutput
```
